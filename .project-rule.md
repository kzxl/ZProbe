# ZeroProbe Project Directives
- Follow Universe Plugin Architecture: new tools must implement `ITool` and self-register in `ToolRegistry` with zero core modifications.
- Decouple heavy network sockets & raw ICMP/TCP packets into the Go Engine daemon via JSON streaming IPC over stdout.
- Adhere to WPF UI and Theming Standards (`[AgentOption]/standards/csharp/wpf-ui.md`).
- Ensure all asynchronous calls use proper cancellation tokens and dispatcher safety.
